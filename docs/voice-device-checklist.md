# Voice on real phones: device checklist

*Refresh Phase 6, November 2026.* What can't be tested from a cloud browser: a real
mic, a real screen lock, a real pocket. About 30 minutes per phone. Note what you
see against each line (✓, ✗, or what happened instead) and send it back.

## Before you start

- [ ] Install Hablaba as an app: Safari → Compartir → Añadir a pantalla de inicio
      (iPhone); Chrome → ⋮ → Instalar app (Android). Open it from the home screen
      icon, not the browser, for every test below.
- [ ] Note the phone, the OS version and the battery level. Low Power Mode (iPhone)
      or Battery Saver (Android) off unless a step says otherwise.
- [ ] Headphones out for the first run; the speaker is the harder case.

## iPhone (iOS 17 or 18)

**Starting**
- [ ] Open any charla and tap the mic. Allow the microphone when asked.
- [ ] Once Elena is talking, the screen turns dark green by itself: "Te escucho",
      a timer, a big **Pausa** and **Mantén para terminar**.
- [ ] Under the buttons: "En iPhone la pantalla tiene que quedar prendida. La
      dejamos prendida por ti."

**The 10-minute run (the acceptance test)**
- [ ] Put the phone down, don't touch it, and talk for 10 minutes.
- [ ] The screen stays on the whole time (it doesn't dim and lock).
- [ ] The conversation doesn't pause or drop. Note the time if it does.
- [ ] Elena still hears you at the end as well as at the start.

**Controls**
- [ ] **Pausa** stops her listening ("En pausa"); **Seguir** brings her back.
- [ ] A quick tap on **Mantén para terminar** does nothing.
- [ ] Holding it for about a second fills it terracotta and ends the conversation.
      The thread and its review appear.
- [ ] **Salir del bolsillo** goes back to the normal view; the conversation carries
      on. **Modo bolsillo** under the controls brings the dark view back.
- [ ] Every button is easy to hit with a thumb without looking closely.

**Leaving the screen (expected to pause on iPhone)**
- [ ] Press the side button to lock the phone mid-conversation, then unlock. The
      thread says it paused when you left the screen, and that on iPhone this
      happens if the screen turns off or you switch apps. Nothing is lost.
- [ ] Same again, but swipe to another app and come back.
- [ ] Turn on Low Power Mode and start a new conversation. Does the dark view still
      say the screen is held on, or does it show "Este iPhone no nos deja mantener
      la pantalla prendida…"? Either is fine; note which.

**Interruptions**
- [ ] Have someone call you mid-conversation. Note what Hablaba shows afterwards.
- [ ] Start Maps directions or a voice note in another app. Note what happens.

## Android (Chrome, installed)

**Starting**
- [ ] Open a charla and tap the mic. The normal voice console shows, with
      **Modo bolsillo** underneath (it doesn't open by itself on Android).
- [ ] No iPhone note appears.
- [ ] Tap **Modo bolsillo**: the dark view with the same controls.

**The 10-minute run**
- [ ] Same as the iPhone run, with the screen on: no pause, no drop.
- [ ] Then lock the phone with the side button and keep talking for 3 minutes.
      On Android the conversation should carry on with the screen off.
- [ ] Unlock: still live, the timer kept counting, the controls work.
- [ ] Notification shade / lock screen: is there a media control for Hablaba
      (pause/resume)? Does it work?

**Controls**
- [ ] Pausa / Seguir, the press-and-hold end and Salir del bolsillo, as on iPhone.

**Battery managers** (Samsung, Xiaomi, OnePlus especially)
- [ ] Screen off for 5 minutes mid-conversation. If it drops, note the brand and
      what the thread showed when you came back.

## Report back

For each phone: model, OS, ✓/✗ per line, and anything that surprised you. A
screen recording of the 10-minute run (just the start and end) helps a lot.

## Cuentos (both phones, installed app)

Use a picture book you own. Note ✓, ✗ or what happened instead.

- [ ] Frases → Cuentos opens the shelf; the privacy note shows once.
- [ ] "Escanear un cuento" → the camera opens with the dashed frame. On Android,
      "Luz" turns the torch on and off (no torch button on iPhone is expected).
- [ ] Photograph a spread: "Leyendo la página…" then "Traduciendo…" then both
      texts. Time from the shutter to reading the Spanish: under a minute?
- [ ] Text over an illustration: how much did you have to fix?
- [ ] "Elegir de las fotos" offers your photo library (not just the camera).
- [ ] iPhone: a photo from the library that was taken as HEIC opens fine.
- [ ] Reader: the Spanish is readable at arm's length on the default size.
- [ ] Tap a word: Elena says it. Tap it again with flight mode on: still plays.
- [ ] "Leer" reads the page and stops on "Pausa". Nothing ever plays by itself.
- [ ] Luz baja at night: comfortable, nothing glaring.
- [ ] The screen stays on while the reader is open.
- [ ] Flight mode, close the app, reopen it, open the book: photo and Spanish
      are there.
- [ ] iPhone: leave the app unused for a week (installed): are the books still there?
